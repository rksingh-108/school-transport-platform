# @school-transport/web

Next.js app (App Router, TypeScript, Tailwind CSS). Part of the
`school-transport-platform` monorepo — see the [repository root README](../../README.md)
and [docs/architecture.md](../../docs/architecture.md#5-frontend-composition) for
how this app is organized and what runs where.

Run from the repository root, not from this directory directly:

```bash
pnpm install
pnpm --filter @school-transport/web dev
```
